# ABTSTORY Guide

Read BEFORE writing an essay opening, abstract, science or strategy narrative, keynote text, or blog post with `using ABTSTORY`. ABT = And, But, Therefore (Randy Olson). Story Spine = Once upon a time, Every day, Until one day, Because of that, Until finally, Ever since (Kenn Adams).

## 1. Decide Whether ABT Fits

Use ABT when the facts are correct but read like a list, and the reader needs a reason to keep reading. ABT turns "this AND this AND this" into context, a conflict, and a consequence. Typical outputs: science communication, strategy narratives, essay and blog openings, abstracts, keynote scripts, project pitches.

Tell the user that a different technique fits better, and keep `ABTSTORY` until the user decides (`DRSYNART-DD-08`), when:
- The reader is a decision-maker who needs the answer first: use `MINTO` (ABT can still shape its opening paragraph)
- The reader must see the complete evidence set: use `IMRAD`
- The text is a product page for a cold prospect: use `PAS`

ABT works at three sizes: one sentence (a logline), one paragraph (an opening or abstract), or the arc of the whole document. Pick the size before writing.

## 2. Plan Before Writing

1. Write the AND part: the accepted context in 1-2 facts the reader already agrees with
2. Write the BUT part: the one contradiction, problem, or surprise. Choose exactly one; if several compete, pick the one with the strongest evidence
3. Write the THEREFORE part: what follows from the conflict, stated as a consequence, finding, or action
4. Test the logline: read the three parts as one sentence. If it still sounds like a list, the BUT is not a real conflict
5. Decide where Story Spine is needed: only for embedded cases that unfold over time (one team, one experiment, one product launch)

## 3. Execute Each Section

1. Opening: the ABT paragraph. AND in 1-2 sentences, BUT in 1 sentence with a number or concrete fact, THEREFORE in 1-2 sentences
2. Body sections: each section develops one consequence of the THEREFORE. Long documents may use a smaller ABT inside a section to restart momentum
3. Embedded case: tell it with the Story Spine sequence in 4-6 sentences, then return to the main argument
4. Closing: state what the reader now understands or should do, linked back to the original BUT

## 4. When the User Also Passes a Persona

- This section applies only when the user passes `as <persona>`. Without it, apply no persona and do not pick one from the list below (`DRSYNART-DD-08`)
- Fitting personas, offered only when the user asks for persona help: `INTELLECTUAL` (science synthesis), `FOUNDER-ESSAYIST` (counter-intuitive essays), `SECTOR-COLUMNIST` (industry essays), `INVESTIGATIVE-JOURNALIST` (investigation summaries), `JOEL-SPOLSKY` (engineering essays)
- High Humor personas may phrase the BUT with wit, but the BUT must still state a fact
- Persona trait Myth-First Contrast fits naturally into the BUT sentence; do not stack a second trait in the same paragraph
- Persona style must not invent drama: if the evidence shows a small effect, the BUT states a small effect

## 6. Strategic Review Questions

Used by `/critique` after writing:
- Is the BUT a real conflict supported by evidence, or a manufactured twist?
- Did the single tension hide other explanations that the evidence still supports?
- Would the document have worked better as a component inside SCQA or a feature story?
